# ورود و استخراج سؤال‌ها

## هدف مشخص

سؤال‌های منابع موجود باید استخراج و برای دسته‌بندی، ارتباط با کنکور و استفاده در تولید سؤال قابل استفاده شوند.

منابع مدنظر: گاج، قلم‌چی، گزینه‌۲، سنجش، ماز و کنکور اصلی.

## قواعد مرتبط با مدل سؤال

- سؤال واردشده یک موجودیت مستقل است.
- نداشتن سؤال کنکور مرتبط نباید مانع ثبت سؤال شود.
- صرف شباهت سؤال‌ها نباید به‌عنوان منشأ واقعی تولید ثبت شود.
- دسته‌بندی آموزشی، ارتباط با کنکور و منشأ تولید مستقل‌اند.

## اطلاعات نامشخص

- فرمت فایل ورودی، از جمله PDF متنی، اسکن، تصویر یا دادهٔ ساختاریافته: نمی‌دانم؛ اطلاعی ندارم.
- نمونه فایل و کیفیت منابع: نمی‌دانم؛ اطلاعی ندارم.
- وجود پاسخ‌نامه و نوع پاسخ‌ها: نمی‌دانم؛ اطلاعی ندارم.
- روش استخراج متن، فرمول، تصویر و گزینه‌ها: نمی‌دانم؛ اطلاعی ندارم.
- روش تشخیص سؤال تکراری و نسخه‌های متفاوت: نمی‌دانم؛ اطلاعی ندارم.
- روش بازبینی و اصلاح خطای استخراج: نمی‌دانم؛ اطلاعی ندارم.
- اطلاعات دقیق منبع که باید ذخیره شوند: نمی‌دانم؛ اطلاعی ندارم.
- مجوز دریافت، پردازش و انتشار محتوای منابع: نمی‌دانم؛ اطلاعی ندارم.

## محدودیت فعلی

هیچ ابزار OCR، فرمت ذخیره‌سازی یا خط لولهٔ استخراج در این سند انتخاب نشده است. پیش از انتخاب روش، نمونهٔ واقعی ورودی باید مشخص شود.
