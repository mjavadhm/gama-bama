# معیارهای پذیرش اولیه

وضعیت: فقط معیارهای مدل مفهومی سؤال‌ها روشن‌اند. معیارهای کل محصول هنوز کامل نیستند.

## معیارهای مدل سؤال

- [ ] سؤال بدون سؤال کنکور مرتبط قابل ثبت باشد.
- [ ] یک سؤال بتواند به چند سؤال کنکور مرتبط شود.
- [ ] یک سؤال کنکور بتواند با چند سؤال دیگر مرتبط شود.
- [ ] سؤال جدید بتواند چند سؤال مبنای تولید داشته باشد.
- [ ] سؤال‌های مبنای تولید بتوانند از منابع مؤسسات باشند و الزاماً سؤال کنکور نباشند.
- [ ] مبنای تولید و سؤال کنکور مرتبط مستقل از هم ثبت شوند.
- [ ] سؤال ترکیبی بتواند چند مبحث یا فصل مرتبط داشته باشد.
- [ ] تغییر یکی از سه نوع رابطه، دو نوع دیگر را بدون درخواست صریح تغییر ندهد.
- [ ] صرف ارتباط یا شباهت سؤال‌ها، رابطهٔ منشأ تولید ایجاد نکند.

این موارد برای تطبیق با `data-model.md` هستند و به معنی تصمیم دربارهٔ UI، API یا ساختار جداول نیستند.

## معیارهای هنوز نامشخص

- دقت قابل‌قبول استخراج متن، فرمول، تصویر و گزینه‌ها: نمی‌دانم؛ اطلاعی ندارم.
- صحت علمی لازم و روش تأیید سؤال و پاسخ: نمی‌دانم؛ اطلاعی ندارم.
- میزان شباهت یا تفاوت مجاز با سؤال مبنا: نمی‌دانم؛ اطلاعی ندارم.
- صحت و جزئیات ارجاع به کتاب: نمی‌دانم؛ اطلاعی ندارم.
- زمان پاسخ، حجم پردازش و هزینهٔ قابل‌قبول: نمی‌دانم؛ اطلاعی ندارم.
- جریان‌های کاربری لازم برای پذیرش نسخهٔ اول: نمی‌دانم؛ اطلاعی ندارم.

## شیوهٔ استفاده

برای معیارهای روشن، تست رفتار واقعی مطابق `../AGENTS.md` طراحی کن. برای معیارهای نامشخص، عدد یا شرط قبولی ساختگی تعیین نکن؛ ابتدا تصمیم لازم را بگیر.
